# RPA Setup Portal

Сайт-инсталлятор для подготовки рабочего места к обучению созданию персональных RPA-роботов через Claude.
Пошаговая инструкция для Windows и macOS: аккаунты, Claude Desktop, Python 3.12, Git, GitLab CLI, Node.js.

Один статичный файл `index.html` без внешних зависимостей — работает онлайн (GitHub Pages) и офлайн.

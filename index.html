Перед началом

Проверьте, что компьютер подходит. Если что-то не так — сразу обратитесь к ИТ-поддержке.

Операционная система

Windows 10 (версия 1809+) или Windows 11, 64-bit. Команда winget уже встроена.

macOS 13 Ventura или новее, на Apple Silicon (M1–M4) или Intel. Программы ставятся через Homebrew.

Права администратора

Желательны — для установки программ и корректного прописывания в PATH.

Нужен пароль от вашей учётной записи Mac: Homebrew попросит его при установке.

Доступ в интернет

Открыт доступ к доменам:

claude.aiclaude.comgithub.comgitlab.compython.orgwingetbrew.shraw.githubusercontent.comghcr.io

Аккаунты

Claude, GitHub и GitLab. Нет аккаунта — зарегистрируйтесь на шаге 1, это бесплатно.

VS Code и другие редакторы не нужны. Инструкция показана для WindowsmacOS — сменить систему можно переключателем вверху страницы.

Claude Desktop

≈ 2–3 мин

Настольное приложение Claude — в нём мы будем создавать роботов.

  1. Нажмите «Скачать Claude Desktop» — откроется официальная страница, там выберите «Download for Windows». Скачается файл вида Claude-Setup-x64.exe.
  2. Запустите скачанный .exe и пройдите мастер установки со значениями по умолчанию.
  3. Откройте Claude из меню «Пуск» и войдите в тот же аккаунт Claude, что на шаге 1.
  1. Нажмите «Скачать Claude Desktop» — откроется официальная страница, там выберите «Download for macOS». Скачается файл Claude.dmg.
  2. Откройте Claude.dmg из «Загрузок» и перетащите значок Claude в папку «Программы» (Applications).
  3. Запустите Claude из Launchpad или папки «Программы». Если macOS спросит, открыть ли приложение из интернета, — нажмите «Открыть».
  4. Войдите в тот же аккаунт Claude, что на шаге 1.
Скачать Claude Desktop claude.ai/download · официальный источник
Скачивайте только с официального сайта claude.ai / claude.com. Сторонние «зеркала» и версии из Microsoft Store не используйте.

Инструменты командной строки

≈ 5 мин

Python 3.12, Git, GitHub CLI, GitLab CLI и Node.js (нужен для MCP-серверов Claude) ставятся одним блоком команд через wingetпарой команд через Homebrew.

Python 3.12Язык для роботов
GitКонтроль версий
GitHub CLIКоманда gh
GitLab CLIКоманда glab
Node.js LTSДля MCP-серверов

1. Установите всё одной вставкой

Откройте PowerShell или «Терминал» (Пуск → введите «PowerShell»), нажмите «Копировать» и вставьте блок целиком (Ctrl+V или правый клик), затем Enter.

PowerShell
winget install -e --id Python.Python.3.12 -s winget --accept-source-agreements --accept-package-agreements
winget install -e --id Git.Git -s winget --accept-source-agreements --accept-package-agreements
winget install -e --id GitHub.cli -s winget --accept-source-agreements --accept-package-agreements
winget install -e --id GLab.GLab -s winget --accept-source-agreements --accept-package-agreements
winget install -e --id OpenJS.NodeJS.LTS -s winget --accept-source-agreements --accept-package-agreements
Установка идёт 3–5 минут, не закрывайте окно. Windows несколько раз спросит «Разрешить этому приложению вносить изменения?» — каждый раз нажимайте «Да». Если программа уже стоит, winget напишет Found an existing package already installed или No available upgrade found — это нормально, ничего делать не нужно.

2. Перезапустите терминал и проверьте

Закройте и заново откройте PowerShell, чтобы обновился PATH. Затем выполните:

PowerShell
python --version
git --version
gh --version
glab --version
node --version

1. Откройте Терминал и проверьте Homebrew

Нажмите ⌘+Пробел, введите «Терминал» и нажмите Enter. Затем выполните:

Терминал
brew --version

Показалась версия Homebrew 4.x — сразу переходите к пункту 4. Пишет command not found — сделайте пункты 2 и 3.

2. Установите Homebrew

Официальная команда с сайта brew.sh:

Терминал
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
Терминал попросит пароль от Mac: при вводе символы не отображаются, это нормально. Затем нажмите Enter для подтверждения. Если macOS предложит установить «Инструменты командной строки» (Command Line Tools), нажмите «Установить» и дождитесь окончания.

3. Подключите Homebrew к терминалу

Только для Mac на Apple Silicon (M1–M4). На Intel-Mac этот пункт пропустите. Узнать процессор: меню Apple → «Об этом Mac» → строка «Чип» (Apple M…) или «Процессор» (Intel).

Терминал
echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
eval "$(/opt/homebrew/bin/brew shellenv)"

4. Установите все инструменты одной командой

Терминал
brew install python@3.12 git gh glab node

5. Перезапустите терминал и проверьте

Закройте окно Терминала (⌘+Q) и откройте заново. Затем выполните:

Терминал
python3.12 --version
git --version
gh --version
glab --version
node --version

Что должно получиться

Каждая команда выводит номер версии:

pythonpython3.12Python 3.12.x
gitgit version 2.x
ghgh version 2.x
glabglab 1.x
nodev22.x или новее
Команда «не распознаётся»? Перезапустите терминал ещё раз или выйдите из Windows и войдите снова.
Пишет command not found? Перезапустите Терминал. Если не помогло — выполните пункт 3 и повторите проверку.
ШАГ 4

Вход в GitHub CLI и GitLab CLI

≈ 2 мин

Свяжите gh и glab со своими аккаунтами GitHub и GitLab из шага 1. Команды длинные, потому что в них уже вписаны ответы на технические вопросы — просто скопируйте их кнопкой.

1. GitHub CLI

PowerShellТерминал
gh auth login --hostname github.com --git-protocol https --web
  1. На вопрос Authenticate Git with your GitHub credentials? (Y/n) нажмите Enter (это «да»).
  2. Терминал покажет одноразовый код вида ABCD-1234 — запомните его и нажмите Enter, откроется браузер.
  3. Войдите в тот же аккаунт GitHub, введите код, нажмите Continue → Authorize. В терминале появится ✓ Logged in as ….

2. GitLab CLI

PowerShellТерминал
glab auth login --hostname gitlab.com --web --git-protocol https --container-registry-domains "gitlab.com,gitlab.com:443,registry.gitlab.com"
  1. На вопрос Authenticate Git with your GitLab credentials? нажмите Enter (выбрано «Yes»).
  2. Откроется браузер: войдите в тот же аккаунт GitLab и нажмите Authorize.
  3. В терминале появится ✓ Logged in to gitlab.com as …. Если браузер не открылся — скопируйте ссылку из терминала в браузер.

Если не работает

Типовые проблемы и их решения. Нажмите на симптом, чтобы раскрыть.

brew: command not found после установки Homebrew

Причина: Homebrew не подключён к терминалу (Mac на Apple Silicon).

Решение: выполните пункт 3 шага 3 и перезапустите Терминал.

Появилось окно «Установить инструменты командной строки»

Причина: Homebrew нужны Command Line Tools от Apple.

Решение: нажмите «Установить», дождитесь окончания (5–10 минут) и повторите команду установки Homebrew.

macOS не даёт открыть Claude

Причина: защита Gatekeeper при первом запуске.

Решение: откройте «Системные настройки» → «Конфиденциальность и безопасность», внизу нажмите «Всё равно открыть». Скачивайте Claude только с claude.ai/download.

python3.12 / gh / glab не находится после установки

Решение: закройте Терминал (⌘+Q) и откройте заново. Если не помогло — выполните пункт 3 шага 3 и проверьте снова.

winget не распознан

Причина: «App Installer» (в нём живёт winget) ещё не зарегистрирован — так бывает на новом компьютере — или его нет в старой Windows.

Решение: выполните в PowerShell команду ниже и откройте PowerShell заново:

Add-AppxPackage -RegisterByFamilyName -MainPackage Microsoft.DesktopAppInstaller_8wekyb3d8bbwe

Не помогло — установите или обновите «App Installer» в Microsoft Store, либо обновите Windows. Если Store закрыт в организации — обратитесь в ИТ.

gh / glab / python не распознаётся после установки

Причина: не обновился PATH.

Решение: закройте и снова откройте терминал; при необходимости выйдите из Windows и войдите снова.

python --version показывает не 3.12 (например, 3.13 или 3.9)

Причина: на компьютере уже был другой Python, и Windows находит его первым. Python 3.12 при этом установился рядом — это не ошибка.

Решение: проверьте командой py -3.12 --version — должно показаться Python 3.12.x. Если так — отметьте пункт в чек-листе и скажите ведущему, что у вас две версии Python.

Запрос согласия с условиями источника winget

Причина: первый запуск winget.

Решение: нажмите Y и повторите команду.

Claude Desktop не ставится или не открывается

Причина: политики безопасности или антивирус.

Решение: запустите установщик от имени администратора (правый клик → «Запуск от имени администратора»). Скачивайте только с claude.ai/download.

gh auth login «завис» на вопросе

Причина: команда ждёт ответа в терминале — например, на «Authenticate Git with your GitHub credentials? (Y/n)» или «Press Enter to open github.com».

Решение: кликните в окно терминала и нажмите Y или Enter. Если браузер не открылся — откройте github.com/login/device и введите код из терминала.

Окно «Разрешить этому приложению вносить изменения?»

Причина: Git, GitHub CLI и Node.js ставятся для всех пользователей компьютера.

Решение: нажмите «Да». Если просит пароль администратора, которого у вас нет, — обратитесь в ИТ.

No package found matching input criteria

Причина: опечатка в команде или устаревший каталог winget.

Решение: копируйте команды только кнопкой «Копировать». Если ошибка повторяется — выполните winget source update и повторите.

Нет аккаунта на одном из сервисов

Решение: зарегистрируйтесь по кнопке «Зарегистрироваться» на шаге 1 — это бесплатно.

Корпоративный прокси блокирует загрузку

Причина: ограничения корпоративной сети.

Решение: обратитесь в ИТ-поддержку для разблокировки доменов: claude.ai, claude.com, github.com, gitlab.com, python.org и источников winget/Microsoftbrew.sh, raw.githubusercontent.com, ghcr.io.
